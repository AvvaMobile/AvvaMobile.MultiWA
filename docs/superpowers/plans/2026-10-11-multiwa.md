# MultiWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build MultiWA, an Electron desktop app that runs several WhatsApp Web accounts in one window as tabs (one isolated session partition per account), with Sidekick's tab bar, multi-window tabs, split pane, notifications, persistence, security posture and packaging.

**Architecture:** Electron main process owns every privileged capability (windows, `WebContentsView`s, sessions, permissions, downloads, persistence); one `AccountRuntime` per account wraps a `WebContentsView` on `persist:wa-<id>`; a trusted React shell renderer draws the tab strip, splitter, right-pane header, offline page and toasts and talks to main through a narrow typed `contextBridge`. Pure domain modules (`src/domain`) carry geometry, ordering, naming and the title→unread parser and are unit-tested without Electron.

**Tech Stack:** Electron 44 (`WebContentsView`), TypeScript 5.9, electron-vite 5, Vite 7, React 19, electron-builder 26, electron-updater 6.8, Vitest 4 + happy-dom. Node ≥ 22.12. No native modules.

**Spec:** `docs/superpowers/specs/2026-10-11-multiwa-design.md` — read it first; this plan argues from it.

**Source of ported code:** `../AvvaMobile.Sidekick` (sibling folder). Where a step says "ported from Sidekick `<path>`", the code block in this plan is already the adapted version; copy the block, not the Sidekick file.

## Global Constraints

- Product name `MultiWA`; app id `com.avvamobile.multiwa`; GitHub repository `AvvaMobile/MultiWA`; user-data folder `<appData>/AvvaMobile.MultiWA` (env `MULTIWA_USER_DATA` overrides).
- UI language: English. Commit messages: English, prefixed `feat:` / `fix:` / `test:` / `docs:` / `chore:` / `refactor:`.
- Remote WhatsApp content: `nodeIntegration:false`, `contextIsolation:true`, `sandbox:true`, `webSecurity:true`, **no preload, no bridge, no DOM scripting**. The only page signal MultiWA reads is the window title.
- One session partition per account: `persist:wa-<accountId>`. Nothing from the page (cookies, titles, notification bodies, URLs with query strings) is persisted or logged.
- Layout changes (tab switch, split, move between windows) call only `setBounds` / `setVisible` / `addChildView` / `removeChildView`; never `loadURL`, `reload` or `close` on a view.
- No `.github/workflows`; releases are built and uploaded locally (`gh release`). Never push a release tag that triggers CI.
- Node ≥ 22.12; Electron `^44.5.1`; `electron-builder` pinned `26.15.3`; `electron-updater` pinned `6.8.9`.
- Every IPC handler validates `event.senderFrame` (bundled shell page, main frame of a known shell window) and the input shape before acting.
- Tests: Vitest, `src/**/*.test.ts(x)`, run with `npm test`; typecheck with `npm run typecheck`. Both must pass before every commit.

## Review Focus

Input classes the spec implies but tests would otherwise miss; each is pinned to a test in the owning task:

1. **Title formats WhatsApp actually emits** — `"(3) WhatsApp"`, `"WhatsApp"`, `"(12) WhatsApp Business"`, `"‎(3) WhatsApp"` (leading left-to-right mark U+200E) → counts 3, 0, 12, 3; anything unparseable → 0, never NaN. (Task 2)
2. **Filename collisions and hostile names in downloads** — `../../etc/passwd`, empty name, `CON` on Windows, 300-char names, same name twice → safe basename, `name (2).ext`, never outside the Downloads folder. (Task 6)
3. **A removed account's view still receiving events** — `page-title-updated` / `render-process-gone` after `dispose()` must not touch state or crash. (Task 9)
4. **Right pane holding the account that is being activated, moved or removed** — swap on activate, right pane closes on move/remove, ratio untouched. (Task 8)
5. **Top-level navigation to WhatsApp look-alikes** — `https://web.whatsapp.com.evil.com/`, `http://web.whatsapp.com/`, `https://whatsapp.com@evil.com/` → blocked; `https://web.whatsapp.com/`, `https://static.whatsapp.net/x.js` → allowed. (Task 5)

```ts
  showInRightPane(id: string): Promise<void>;
```

```js
const { join } = require('node:path');

const ua = (s) => s.replace(/\s*Electron\/\S+/g, '').replace(/(\(KHTML, like Gecko\))\s+.*?\s*(Chrome\/)/, '$1 $2').replace(/\s{2,}/g, ' ').trim();
```

```ts
/** Fixed chrome of the shell window: the tab strip on top; the work area (panes) is everything below it. */
export const TOPBAR_HEIGHT = 44;
/** Header drawn by the shell above the right pane (account name + close). */
export const RIGHT_PANE_HEADER_HEIGHT = 28;

export interface Rect { x: number; y: number; width: number; height: number; }

export function workAreaFor(contentWidth: number, contentHeight: number): Rect {
  return { x: 0, y: TOPBAR_HEIGHT, width: Math.max(0, contentWidth), height: Math.max(0, contentHeight - TOPBAR_HEIGHT) };
}
```

```ts
import { app, BrowserWindow, nativeImage } from 'electron';
import { existsSync } from 'node:fs';
import { join } from 'node:path';
import { startShell } from './app/ShellApp';

const APP_NAME = 'MultiWA';
app.setName(APP_NAME);
// Windows groups taskbar entries and attributes notifications by this id.
if (process.platform === 'win32') app.setAppUserModelId('com.avvamobile.multiwa');
// Profile (accounts, WhatsApp sessions, logs) lives in appData/AvvaMobile.MultiWA; MULTIWA_USER_DATA selects another one.
app.setPath('userData', process.env.MULTIWA_USER_DATA || join(app.getPath('appData'), 'AvvaMobile.MultiWA'));

// Global hardening for every webContents (local and remote).
app.on('web-contents-created', (_event, contents) => {
  contents.on('will-attach-webview', (e) => e.preventDefault());
});

// One instance per profile: a second launch focuses the running one instead of opening the same partitions twice.
if (!app.requestSingleInstanceLock()) app.exit(0);
let focusMainWindow: (() => void) | null = null;
app.on('second-instance', () => {
  if (focusMainWindow) return focusMainWindow();
  const win = BrowserWindow.getAllWindows()[0];
  if (!win) return;
  if (win.isMinimized()) win.restore();
  win.show();
  win.focus();
});
process.on('SIGTERM', () => app.quit());

app.whenReady().then(async () => {
  const icon = join(__dirname, '../../build/icon.png');
  if (process.platform === 'darwin' && existsSync(icon)) app.dock?.setIcon(nativeImage.createFromPath(icon));
  ({ focusMainWindow } = await startShell());
});
```

```ts
import { app, BrowserWindow } from 'electron';
import { join } from 'node:path';

export async function startShell(): Promise<{ focusMainWindow: () => void }> {
  const win = new BrowserWindow({
    width: 1400,
    height: 900,
    minWidth: 900,
    minHeight: 560,
    title: 'MultiWA',
    backgroundColor: '#111b21',
    show: false,
    webPreferences: { preload: join(__dirname, '../preload/shell.js'), contextIsolation: true, sandbox: true, nodeIntegration: false, webSecurity: true, spellcheck: false },
  });
  win.once('ready-to-show', () => win.show());
  win.webContents.on('will-navigate', (e) => e.preventDefault());
  win.webContents.setWindowOpenHandler(() => ({ action: 'deny' }));
  if (process.env.ELECTRON_RENDERER_URL) await win.loadURL(`${process.env.ELECTRON_RENDERER_URL}/shell/index.html`);
  else await win.loadFile(join(__dirname, '../renderer/shell/index.html'));
  app.on('window-all-closed', () => app.quit());
  return {
    focusMainWindow: () => {
      if (win.isDestroyed()) return;
      if (win.isMinimized()) win.restore();
      win.show();
      win.focus();
    },
  };
}
```

```ts
/**
 * Split-pane geometry for the work area: left account | splitter | right account.
 * Pure functions shared by the shell renderer (splitter drag) and the main process (view bounds),
 * so both sides always agree.
 */

/** Fraction of the work area given to the left pane. */
export type SplitRatio = number;

export const DEFAULT_SPLIT_RATIO: SplitRatio = 0.5;
export const MIN_PANE_WIDTH = 360;
export const SPLITTER_WIDTH = 6;

export interface Rect { x: number; y: number; width: number; height: number; }

export interface SplitGeometry { left: Rect; splitter: Rect; right: Rect; }

export function isValidSplitRatio(value: unknown): value is SplitRatio {
  return typeof value === 'number' && Number.isFinite(value) && value > 0 && value < 1;
}

/** Clamps a ratio so neither pane drops below MIN_PANE_WIDTH; a too-narrow area is shared equally. */
export function clampSplitRatio(ratio: number, workAreaWidth: number): SplitRatio {
  const r = Number.isFinite(ratio) ? Math.min(1, Math.max(0, ratio)) : DEFAULT_SPLIT_RATIO;
  const usable = workAreaWidth - SPLITTER_WIDTH;
  if (!(usable > 0)) return isValidSplitRatio(r) ? r : DEFAULT_SPLIT_RATIO;
  if (usable < 2 * MIN_PANE_WIDTH) return 0.5;
  const min = MIN_PANE_WIDTH / usable;
  return Math.min(1 - min, Math.max(min, r));
}

/** Ratio for a splitter dragged to `pointerX` (relative to the work area's left edge). */
export function ratioFromPointer(pointerX: number, workAreaWidth: number): SplitRatio {
  const usable = workAreaWidth - SPLITTER_WIDTH;
  if (!(usable > 0)) return DEFAULT_SPLIT_RATIO;
  return clampSplitRatio((pointerX - SPLITTER_WIDTH / 2) / usable, workAreaWidth);
}

/** Integer pixel geometry for a work area at (`area.x`, `area.y`). */
export function computeSplitGeometry(area: Rect, ratio: number): SplitGeometry {
  const usable = Math.max(0, area.width - SPLITTER_WIDTH);
  const leftWidth = Math.round(usable * clampSplitRatio(ratio, area.width));
  const rightWidth = Math.max(0, usable - leftWidth);
  return {
    left: { x: area.x, y: area.y, width: leftWidth, height: area.height },
    splitter: { x: area.x + leftWidth, y: area.y, width: SPLITTER_WIDTH, height: area.height },
    right: { x: area.x + leftWidth + SPLITTER_WIDTH, y: area.y, width: rightWidth, height: area.height },
  };
}
```

```ts
/**
 * Single source of truth for every remote origin MultiWA trusts. Any change here must be reflected in origins.test.ts.
 */

export const WHATSAPP_APP_HOST = 'web.whatsapp.com';
export const WHATSAPP_HOME_URL = 'https://web.whatsapp.com/';
export const WHATSAPP_ORIGIN = 'https://web.whatsapp.com';

/** Registrable domains whose https hosts the account view may navigate to at top level. */
const ALLOWED_DOMAINS: readonly string[] = ['whatsapp.com', 'whatsapp.net'];

/** Chromium session partition of one account (its cookies, IndexedDB, cache, service workers). */
export function partitionFor(accountId: string): string {
  return `persist:wa-${accountId}`;
}

function parseHttps(raw: string): URL | null {
  let url: URL;
  try {
    url = new URL(raw);
  } catch {
    return null;
  }
  if (url.protocol !== 'https:') return null;
  // Credentials in URLs and non-default ports are never part of legitimate flows.
  if (url.username || url.password || url.port) return null;
  return url;
}

const hostInDomain = (host: string, domain: string) => host === domain || host.endsWith(`.${domain}`);

/** True for https://web.whatsapp.com/... (exact host, default port). */
export function isWhatsAppAppUrl(raw: string): boolean {
  const url = parseHttps(raw);
  return url !== null && url.hostname.toLowerCase() === WHATSAPP_APP_HOST;
}

/** Origin string form ("https://web.whatsapp.com"), as delivered by permission handlers. */
export function isWhatsAppOrigin(origin: string): boolean {
  const url = parseHttps(origin);
  return url !== null && url.origin === origin.replace(/\/$/, '') && url.hostname.toLowerCase() === WHATSAPP_APP_HOST;
}

/** Top-level navigation allowlist for an account view. */
export function isAllowedTopLevelUrl(raw: string): boolean {
  const url = parseHttps(raw);
  if (url === null) return false;
  const host = url.hostname.toLowerCase();
  return ALLOWED_DOMAINS.some((d) => hostInDomain(host, d));
}

/** Only plain web links may be handed to the OS browser. */
export function isSafeExternalUrl(raw: string): boolean {
  let url: URL;
  try {
    url = new URL(raw);
  } catch {
    return false;
  }
  return (url.protocol === 'https:' || url.protocol === 'http:') && !url.username && !url.password;
}
```

```ts
import { isWhatsAppAppUrl, isWhatsAppOrigin } from './origins';

/**
 * Pure permission policy for an account session. Everything not explicitly allowed is denied.
 * Allowed, for the WhatsApp main frame only: media (microphone and camera: voice notes, calls),
 * notifications, clipboard read / sanitized write, fullscreen.
 */
const ALLOWED_SIMPLE = new Set(['notifications', 'clipboard-read', 'clipboard-sanitized-write', 'fullscreen']);

export interface PermissionRequestInput {
  permission: string;
  /** Origin/URL of the frame making the request. */
  requestingUrl: string;
  /** Top-level URL of the webContents, when known. */
  topLevelUrl?: string;
  /** Media types for "media" requests (Electron: details.mediaTypes). */
  mediaTypes?: readonly string[];
  /** Electron: details.isMainFrame. Requests from subframes are denied. */
  isMainFrame?: boolean;
}

export type PermissionDecision = { allow: true; reason: string } | { allow: false; reason: string };

export function decidePermissionRequest(input: PermissionRequestInput): PermissionDecision {
  const fromWhatsApp = isWhatsAppAppUrl(input.requestingUrl) || isWhatsAppOrigin(input.requestingUrl);
  const topIsWhatsApp = input.topLevelUrl === undefined || isWhatsAppAppUrl(input.topLevelUrl);
  if (!fromWhatsApp || !topIsWhatsApp) return { allow: false, reason: `${input.permission}: origin not approved` };
  if (input.isMainFrame === false) return { allow: false, reason: `${input.permission}: subframe request` };

  if (input.permission === 'media') {
    const types = input.mediaTypes ?? [];
    if (types.length === 0) return { allow: false, reason: 'media: unspecified media type' };
    if (!types.every((t) => t === 'audio' || t === 'video')) return { allow: false, reason: 'media: unknown media type' };
    return { allow: true, reason: `media: ${types.join('+')} for WhatsApp` };
  }
  if (ALLOWED_SIMPLE.has(input.permission)) return { allow: true, reason: `${input.permission}: WhatsApp` };
  return { allow: false, reason: `${input.permission}: not allowlisted` };
}

export interface PermissionCheckInput {
  permission: string;
  requestingOrigin: string;
  mediaType?: string;
}

/** Synchronous permission *checks* (Notification.permission, navigator.permissions.query, device labels). */
export function decidePermissionCheck(input: PermissionCheckInput): boolean {
  if (!isWhatsAppOrigin(input.requestingOrigin) && !isWhatsAppAppUrl(input.requestingOrigin)) return false;
  if (input.permission === 'media') return input.mediaType === 'audio' || input.mediaType === 'video';
  return ALLOWED_SIMPLE.has(input.permission);
}
```

```ts
/** Configures one account's session exactly once: UA, permission handlers, device denials. Downloads are left to DownloadManager. */

const EXTERNAL_OPEN_INTERVAL_MS = 2_000;

/** Wraps `fn` so it runs at most once per `intervalMs`; calls in between are dropped (a page must not spam the OS browser). */
export function rateLimited<A extends unknown[]>(fn: (...args: A) => void, intervalMs = EXTERNAL_OPEN_INTERVAL_MS, now: () => number = Date.now): (...args: A) => boolean {
  let last = -Infinity;
  return (...args: A) => {
    const t = now();
    if (t - last < intervalMs) return false;
    last = t;
    fn(...args);
    return true;
  };
}

/** Strip query/fragment (they can carry invite codes) before logging. */
export function redactUrl(raw: string): string {
  try {
    const u = new URL(raw);
    return `${u.origin}${u.pathname}`;
  } catch {
    return '<invalid>';
  }
}

/** Replaces every http(s) URL in free text (e.g. an error message) by its origin and path. */
export function redactUrlsIn(text: string): string {
  return text.replace(/https?:\/\/[^\s'"<>()]+/g, (u) => redactUrl(u));

/**
 * Navigation and window-open policy for an account webContents:
 * - top-level navigation outside whatsapp.com / whatsapp.net is blocked and handed to the OS browser;
 * - every window.open is denied in-app; safe http(s) targets open in the OS browser.
 */
function applyNavigationPolicy(wc: WebContents, onLog?: (e: NavigationLogEntry) => void): void {
  const log = (kind: NavigationLogEntry['kind'], url: string) => onLog?.({ at: new Date().toISOString(), kind, url: redactUrl(url) });
  const openExternal = rateLimited((url: string) => void shell.openExternal(url));

  const guard = (event: { preventDefault(): void }, url: string) => {
    if (isAllowedTopLevelUrl(url)) return log('navigate-allowed', url);
    event.preventDefault();
    log('navigate-blocked', url);
    if (isSafeExternalUrl(url)) openExternal(url);
  };
  wc.on('will-navigate', (event) => guard(event, event.url));
  wc.on('will-redirect', (event) => {
    if (event.isMainFrame) guard(event, event.url);
  });
  wc.on('will-attach-webview', (event) => event.preventDefault());
  wc.setWindowOpenHandler(({ url }) => {
    if (isSafeExternalUrl(url)) {
      log('popup-external', url);
      openExternal(url);
    } else log('popup-blocked', url);
    return { action: 'deny' };
  });
}

/** A hardened, bridge-less WebContentsView on the account's own partition, with navigation policy applied. */
export function createAccountView(accountId: string, hooks: RemoteHooks): WebContentsView {
  const partition = partitionFor(accountId);
  configureAccountSession(session.fromPartition(partition), hooks);
  const view = new WebContentsView({ webPreferences: remoteWebPreferences(partition) });
  applyNavigationPolicy(view.webContents, hooks.onNavigation);
  return view;
}
```

```ts
import { basename, extname, join } from 'node:path';

const MAX_NAME = 120;
const WINDOWS_RESERVED = /^(con|prn|aux|nul|com[1-9]|lpt[1-9])(\..*)?$/i;

/**
 * A safe basename for a file WhatsApp wants to download: no directories, no control or reserved characters,
 * no Windows device names, no leading dots, bounded length. Empty input becomes "download".
 */
export function sanitizeFilename(name: string): string {
  // Take the last path segment of either separator style, then clean it.
  let base = name.split(/[\\/]+/).filter(Boolean).pop() ?? '';
  base = base.replace(/\p{Cc}/gu, '').replace(/[<>:"|?*]/g, '_');
  base = base.replace(/^\.+/, '').replace(/[. ]+$/g, '');
  if (!base) return 'download';
  if (WINDOWS_RESERVED.test(base)) base = `_${base}`;
  if (base.length > MAX_NAME) {
    const ext = extname(base).slice(0, 16);
    base = `${base.slice(0, MAX_NAME - ext.length)}${ext}`;
  }
  return base;
}

/** `dir/<name>`; when taken, `dir/<stem> (2)<ext>`, `(3)`, … Never outside `dir`. */
export function uniquePath(dir: string, filename: string, exists: (path: string) => boolean): string {
  const safe = sanitizeFilename(filename);
  const ext = extname(safe);
  const stem = ext ? safe.slice(0, -ext.length) : safe;
  let candidate = join(dir, safe);
  for (let n = 2; exists(candidate); n++) candidate = join(dir, `${stem} (${n})${ext}`);
  // Defensive: the sanitized name has no separators, so basename(candidate) is the file itself.
  return join(dir, basename(candidate));
}
```

```ts
import { basename } from 'node:path';
import { randomUUID } from 'node:crypto';
import { uniquePath } from './downloadTarget';

export type DownloadEvent =
  | { kind: 'done'; id: string; accountId: string; filename: string; path: string }
  | { kind: 'failed'; id: string; accountId: string; filename: string; state: string };

export interface DownloadManagerDeps {
  downloadsDir: () => string;
  exists?: (path: string) => boolean;
  onEvent: (e: DownloadEvent) => void;
  newId?: () => string;
}

/**
 * Every download of every account session lands in the user's Downloads folder under a free name, with no dialog.
 * Finished downloads are remembered by id so a toast can reveal them later; the renderer never sees a path.
 */
export class DownloadManager {
  private readonly paths = new Map<string, string>();
  private readonly attached = new WeakSet<Session>();

  constructor(private readonly deps: DownloadManagerDeps) {}

  attach(ses: Session, accountId: string): void {
    if (this.attached.has(ses)) return;
    this.attached.add(ses);
    ses.on('will-download', (_event, item: DownloadItem) => {
      const id = (this.deps.newId ?? randomUUID)();
      const target = uniquePath(this.deps.downloadsDir(), item.getFilename(), this.deps.exists ?? existsSync);
      item.setSavePath(target);
      const filename = basename(target);
      item.once('done', (_e, state) => {
        if (state === 'completed') {
          this.paths.set(id, target);
          this.deps.onEvent({ kind: 'done', id, accountId, filename, path: target });
        } else this.deps.onEvent({ kind: 'failed', id, accountId, filename, state });
      });
    });
  }

  pathOf(id: string): string | undefined {
    return this.paths.get(id);
  }

  reveal(id: string): void {
    const p = this.paths.get(id);
    if (p) shell.showItemInFolder(p);
  }
}
```

```ts
const TRANSIENT = new Set(['EPERM', 'EBUSY', 'EACCES']);

/**
 * `renameSync` for atomic saves. On Windows replacing a file fails transiently while another process
 * (antivirus, search indexer, backup) briefly holds it open; retry a few times before giving up.
 */
export function renameWithRetry(from: string, to: string, platform: NodeJS.Platform = process.platform, rename = renameSync): void {
  const attempts = platform === 'win32' ? 5 : 1;
  for (let i = 1; ; i++) {
    try {
      rename(from, to);
      return;
    } catch (err) {
      const code = (err as NodeJS.ErrnoException).code;
      if (i >= attempts || !code || !TRANSIENT.has(code)) throw err;
      Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, 20 * i);
    }
  }
}
```

```ts
import { dirname } from 'node:path';
import type { AccountRecord } from '../../domain/accounts/account';
import { isPermutation } from '../../domain/accounts/order';
import { DEFAULT_SPLIT_RATIO, isValidSplitRatio } from '../../domain/layout/splitPane';
import { renameWithRetry } from './renameWithRetry';

/**
 * Persisted AppState (spec §10). Atomic writes, schema version, corrupt-file recovery, defensive load.
 * Runtime objects (views, sessions, unread counts) are never persisted.
 */
const APP_STATE_SCHEMA_VERSION = 1;
export const MAIN_WINDOW_ID = 'main';

export interface WindowBounds { x: number; y: number; width: number; height: number; }

export interface WindowRecord {
  id: string;
  isMain: boolean;
  bounds: WindowBounds | null;
  activeAccountId: string | null;
  splitRatio: number;
  rightPaneAccountId: string | null;
}

export interface Prefs { lastVersionSeen: string; }

export interface AppState {
  schemaVersion: number;
  accounts: AccountRecord[];
  windows: WindowRecord[];
  prefs: Prefs;
}

const mainWindow = (): WindowRecord => ({ id: MAIN_WINDOW_ID, isMain: true, bounds: null, activeAccountId: null, splitRatio: DEFAULT_SPLIT_RATIO, rightPaneAccountId: null });
const empty = (): AppState => ({ schemaVersion: APP_STATE_SCHEMA_VERSION, accounts: [], windows: [mainWindow()], prefs: { lastVersionSeen: '' } });

const isRecord = (v: unknown): v is Record<string, unknown> => !!v && typeof v === 'object' && !Array.isArray(v);
const str = (v: unknown, fallback = ''): string => (typeof v === 'string' ? v : fallback);

export class AppStateStore {
  private state: AppState;
  private timer: NodeJS.Timeout | null = null;

  constructor(
    private readonly file: string,
    private readonly debounceMs = 150,
    private readonly log: (line: string) => void = (line) => console.error(line),
    private readonly retryMs = 5_000,
  ) {
    this.state = this.load();
  }

  get(): Readonly<AppState> {
    return this.state;
  }

  // ---- accounts ----

  account(id: string): AccountRecord | undefined {
    return this.state.accounts.find((a) => a.id === id);
  }

  /** All accounts in global tab order. */
  accounts(): AccountRecord[] {
    return [...this.state.accounts].sort((a, b) => a.order - b.order);
  }

  addAccount(a: AccountRecord): void {
    this.state.accounts.push(a);
    this.save();
  }

  updateAccount(id: string, patch: Partial<Omit<AccountRecord, 'id'>>): void {
    const a = this.account(id);
    if (!a) throw new Error(`unknown account ${id}`);
    Object.assign(a, patch);
    this.save();
  }

  removeAccount(id: string): void {
    this.state.accounts = this.state.accounts.filter((a) => a.id !== id);
    for (const w of this.state.windows) {
      if (w.activeAccountId === id) w.activeAccountId = null;
      if (w.rightPaneAccountId === id) w.rightPaneAccountId = null;
    }
    this.save();
  }

  /** Persists a new global tab order; `ids` must be a permutation of all account ids. */
  reorderAccounts(ids: readonly string[]): boolean {
    if (!isPermutation(this.accounts().map((a) => a.id), ids)) return false;
    ids.forEach((id, i) => {
      this.account(id)!.order = i;
    });
    this.save();
    return true;
  }

  // ---- windows ----

  window(id: string): WindowRecord | undefined {
    return this.state.windows.find((w) => w.id === id);
  }

  windows(): WindowRecord[] {
    return [...this.state.windows];
  }

  mainWindowRecord(): WindowRecord {
    return this.state.windows.find((w) => w.isMain)!;
  }

  upsertWindow(rec: WindowRecord): void {
    const i = this.state.windows.findIndex((w) => w.id === rec.id);
    if (i >= 0) this.state.windows[i] = rec;
    else this.state.windows.push(rec);
    this.save();
  }

  /** Forgets a secondary window; its accounts go back to the main window. The main window record is never removed. */
  removeWindow(id: string): void {
    const w = this.window(id);
    if (!w || w.isMain) return;
    for (const a of this.state.accounts) if (a.windowId === id) a.windowId = MAIN_WINDOW_ID;
    this.state.windows = this.state.windows.filter((x) => x.id !== id);
    this.save();
  }

  // ---- prefs ----

  prefs(): Prefs {
    return this.state.prefs;
  }

  setPrefs(patch: Partial<Prefs>): void {
    this.state.prefs = { ...this.state.prefs, ...patch };
    this.save();
  }

  // ---- persistence ----

  /** Writes immediately (application shutdown). */
  flush(): void {
    if (this.timer) clearTimeout(this.timer);
    this.timer = null;
    this.write();
  }

  save(): void {
    if (this.debounceMs <= 0) {
      if (!this.write()) this.scheduleRetry();
      return;
    }
    if (this.timer) return;
    this.timer = setTimeout(() => {
      this.timer = null;
      if (!this.write()) this.scheduleRetry();
    }, this.debounceMs);
  }

  /** A failed write (disk full, permissions, a locked file) is retried later, never in a tight loop. */
  private scheduleRetry(): void {
    if (this.timer) return;
    this.timer = setTimeout(() => {
      this.timer = null;
      if (!this.write()) this.scheduleRetry();
    }, this.retryMs);
    this.timer.unref?.();
  }

  private write(): boolean {
    try {
      mkdirSync(dirname(this.file), { recursive: true });
      const tmp = `${this.file}.tmp`;
      writeFileSync(tmp, JSON.stringify(this.state, null, 2));
      renameWithRetry(tmp, this.file);
      return true;
    } catch (err) {
      this.log(`state save failed: ${err instanceof Error ? err.message : String(err)}`);
      return false;
    }
  }

  private load(): AppState {
    let raw: string;
    try {
      raw = readFileSync(this.file, 'utf8');
    } catch {
      return empty();
    }
    try {
      const parsed: unknown = JSON.parse(raw);
      if (!isRecord(parsed) || parsed.schemaVersion !== APP_STATE_SCHEMA_VERSION || !Array.isArray(parsed.accounts)) throw new Error('schema');
      const windowsRaw = Array.isArray(parsed.windows) ? parsed.windows : [];
      const windows: WindowRecord[] = windowsRaw.filter(isRecord).filter((w) => typeof w.id === 'string').map((w) => ({
        id: w.id as string,
        isMain: w.isMain === true || w.id === MAIN_WINDOW_ID,
        bounds: isRecord(w.bounds) && [w.bounds.x, w.bounds.y, w.bounds.width, w.bounds.height].every((n) => typeof n === 'number' && Number.isFinite(n))
          ? { x: w.bounds.x as number, y: w.bounds.y as number, width: w.bounds.width as number, height: w.bounds.height as number }
          : null,
        activeAccountId: str(w.activeAccountId, '') || null,
        splitRatio: isValidSplitRatio(w.splitRatio) ? w.splitRatio : DEFAULT_SPLIT_RATIO,
        rightPaneAccountId: str(w.rightPaneAccountId, '') || null,
      }));
      if (!windows.some((w) => w.isMain)) windows.unshift(mainWindow());
      const windowIds = new Set(windows.map((w) => w.id));
      const accounts: AccountRecord[] = parsed.accounts
        .filter(isRecord)
        .filter((a) => typeof a.id === 'string' && a.id.length > 0)
        .map((a, i) => ({
          id: a.id as string,
          name: str(a.name, `Account ${i + 1}`),
          color: /^#[0-9a-f]{6}$/i.test(str(a.color)) ? (a.color as string).toLowerCase() : '#25d366',
          order: typeof a.order === 'number' && Number.isFinite(a.order) ? a.order : i,
          windowId: typeof a.windowId === 'string' && windowIds.has(a.windowId) ? a.windowId : MAIN_WINDOW_ID,
          createdAt: str(a.createdAt),
        }));
      const accountIds = new Set(accounts.map((a) => a.id));
      for (const w of windows) {
        if (w.activeAccountId && !accountIds.has(w.activeAccountId)) w.activeAccountId = null;
        if (w.rightPaneAccountId && !accountIds.has(w.rightPaneAccountId)) w.rightPaneAccountId = null;
      }
      const prefs: Prefs = { lastVersionSeen: str(isRecord(parsed.prefs) ? parsed.prefs.lastVersionSeen : '') };
      return { schemaVersion: APP_STATE_SCHEMA_VERSION, accounts, windows, prefs };
    } catch {
      try {
        copyFileSync(this.file, `${this.file}.corrupt-${Date.now()}`);
      } catch {
        // ignore
      }
      return empty();
    }
  }
}
```

```ts
import type { AccountView, ShellState } from '../../shared/state';

/**
 * Pure helpers for multiple shell windows. Each account tab lives in exactly one window;
 * a window's renderer only ever sees its own tabs.
 */

/** The full account list narrowed to one window's tabs, with that window's pane state. */
export function stateForWindow(all: readonly AccountView[], inWindow: (id: string) => boolean, activeAccountId: string | null, rightPaneAccountId: string | null, splitRatio: number): ShellState {
  return { accounts: all.filter((a) => inWindow(a.id)), activeAccountId, rightPaneAccountId, splitRatio };
}

/** The tab a window shows after its tabs changed: the current one if it is still there, else its first tab. */
export function nextActiveTab(orderedIds: readonly string[], inWindow: (id: string) => boolean, current: string | null): string | null {
  if (current && inWindow(current) && orderedIds.includes(current)) return current;
  return orderedIds.find(inWindow) ?? null;
}

/**
 * Applies one window's reordered tabs to the global tab order: that window's slots get its new order,
 * every other window's tabs keep their positions. Null unless `windowOrder` is exactly the window's tabs.
 */
export function mergeWindowOrder(globalOrder: readonly string[], inWindow: (id: string) => boolean, windowOrder: readonly string[]): string[] | null {
  const own = globalOrder.filter(inWindow);
  if (own.length !== windowOrder.length || new Set(windowOrder).size !== windowOrder.length || !windowOrder.every((id) => own.includes(id))) return null;
  let i = 0;
  return globalOrder.map((id) => (inWindow(id) ? windowOrder[i++]! : id));
}

const pageKey = (raw: string): string | null => {
  try {
    const u = new URL(raw);
    return decodeURIComponent(`${u.protocol}//${u.host}${u.pathname}`);
  } catch {
    return null;
  }
};

/** Whether `url` is the page `expected` (query and fragment ignored; percent-encoding normalized). */
export function isSamePage(url: string, expected: string): boolean {
  const k = pageKey(url);
  return k !== null && k === pageKey(expected);
}
```

```ts
import { clampSplitRatio, computeSplitGeometry, isValidSplitRatio, type Rect } from '../../domain/layout/splitPane';
import { RIGHT_PANE_HEADER_HEIGHT } from '../../shared/shellLayout';

/** The part of a WebContentsView the layout may touch: geometry and visibility only. */
export interface LayoutView {
  setBounds(bounds: Rect): void;
  setVisible(visible: boolean): void;
}

export interface PaneGeometry {
  left: Rect;
  splitter: Rect | null;
  /** Shell-drawn strip above the right pane (account name + close). */
  rightHeader: Rect | null;
  right: Rect | null;
}

/**
 * Owns the pane layout of one shell window: the active account in the left pane, optionally a second
 * account in the right pane, and the divider ratio. Only ever calls setBounds/setVisible on registered views;
 * it never navigates, reloads or recreates anything (spec §3.4).
 */
export class PaneLayoutController {
  private readonly views = new Map<string, LayoutView>();
  private readonly hidden = new Set<string>();
  private active: string | null = null;
  private right: string | null = null;
  private currentRatio: number;

  constructor(
    private readonly getWorkArea: () => Rect,
    initialRatio: number,
    private readonly onRatioCommit: (ratio: number) => void,
  ) {
    this.currentRatio = isValidSplitRatio(initialRatio) ? initialRatio : 0.5;
  }

  register(id: string, view: LayoutView): void {
    this.views.set(id, view);
    if (id !== this.active && id !== this.right) view.setVisible(false);
  }

  unregister(id: string): void {
    this.views.delete(id);
    this.hidden.delete(id);
    if (this.right === id) this.right = null;
    if (this.active === id) this.active = null;
    this.relayout();
  }

  has(id: string): boolean {
    return this.views.has(id);
  }

  get activeId(): string | null {
    return this.active;
  }

  get rightId(): string | null {
    return this.right;
  }

  /** Effective (clamped) ratio for the current work-area width. */
  get ratio(): number {
    return clampSplitRatio(this.currentRatio, this.getWorkArea().width);
  }

  /** Shows `id` in the left pane. If it was the right pane's account, the two accounts swap panes. */
  activate(id: string): void {
    if (!this.views.has(id)) throw new Error(`unknown account ${id}`);
    if (id === this.active) return this.relayout();
    if (id === this.right) this.right = this.active;
    this.active = id;
    this.relayout();
  }

  /** Shows `id` in the right pane (null closes it). The active account cannot also be the right pane. */
  setRight(id: string | null): void {
    if (id !== null && (!this.views.has(id) || id === this.active)) return;
    this.right = id;
    this.relayout();
  }

  /** Offline mask: the view stays in its slot (bounds follow the layout) but is invisible; the shell draws over it. */
  setHidden(id: string, hidden: boolean): void {
    if (hidden) this.hidden.add(id);
    else this.hidden.delete(id);
    this.relayout();
  }

  geometry(): PaneGeometry {
    const area = this.getWorkArea();
    if (this.right === null) return { left: area, splitter: null, rightHeader: null, right: null };
    const g = computeSplitGeometry(area, this.currentRatio);
    const h = Math.min(RIGHT_PANE_HEADER_HEIGHT, g.right.height);
    return {
      left: g.left,
      splitter: g.splitter,
      rightHeader: { x: g.right.x, y: g.right.y, width: g.right.width, height: h },
      right: { x: g.right.x, y: g.right.y + h, width: g.right.width, height: g.right.height - h },
    };
  }

  /** Live drag update: resizes immediately; nothing is persisted. */
  preview(ratio: number): number {
    return this.update(ratio, false);
  }

  /** End of drag: resizes and persists the clamped ratio. */
  commit(ratio: number): number {
    return this.update(ratio, true);
  }

  /** Re-applies geometry and visibility to every registered view (window resize, slot changes). */
  relayout(): void {
    const g = this.geometry();
    for (const [id, view] of this.views) {
      const slot = id === this.active ? g.left : id === this.right ? g.right : null;
      if (slot) view.setBounds(slot);
      view.setVisible(slot !== null && !this.hidden.has(id));
    }
  }

  private update(ratio: number, persist: boolean): number {
    if (!isValidSplitRatio(ratio)) throw new Error('invalid split ratio');
    this.currentRatio = clampSplitRatio(ratio, this.getWorkArea().width);
    this.relayout();
    if (persist) this.onRatioCommit(this.currentRatio);
    return this.currentRatio;
  }
}
```

```ts
import { parseUnreadFromTitle } from '../../domain/unread/parseTitle';
import type { AccountStatus } from '../../shared/state';

/** One automatic reload per crash within this window; a second crash inside it goes offline (spec §7). */
export const CRASH_RELOAD_WINDOW_MS = 60_000;

export interface RuntimeState {
  status: AccountStatus;
  error: string | null;
  unread: number;
  lastCrashAt: number | null;
}

export type RuntimeEvent =
  | { type: 'load-start' }
  | { type: 'load-finish' }
  | { type: 'load-fail'; code: number; description: string }
  | { type: 'crash'; reason: string }
  | { type: 'title'; title: string }
  | { type: 'reload' };

export const initialRuntimeState = (): RuntimeState => ({ status: 'loading', error: null, unread: 0, lastCrashAt: null });

/** Pure status machine of one account view. `action: 'reload'` tells the runtime to load the page again. */
export function reduceRuntime(state: RuntimeState, event: RuntimeEvent, now: number): { state: RuntimeState; action: 'reload' | null } {
  switch (event.type) {
    case 'load-start':
      return { state: { ...state, status: state.status === 'offline' ? 'offline' : 'loading' }, action: null };
    case 'load-finish':
      return { state: { ...state, status: 'ready', error: null }, action: null };
    case 'load-fail':
      // -3 = ERR_ABORTED: a navigation replaced by another one, not a failure.
      if (event.code === -3) return { state, action: null };
      return { state: { ...state, status: 'offline', error: event.description || `Load failed (${event.code})` }, action: null };
    case 'crash': {
      const recent = state.lastCrashAt !== null && now - state.lastCrashAt < CRASH_RELOAD_WINDOW_MS;
      if (recent) return { state: { ...state, status: 'offline', error: `WhatsApp stopped responding (${event.reason})`, lastCrashAt: now }, action: null };
      return { state: { ...state, status: 'loading', error: null, unread: 0, lastCrashAt: now }, action: 'reload' };
    }
    case 'title':
      return { state: { ...state, unread: parseUnreadFromTitle(event.title) }, action: null };
    case 'reload':
      return { state: { ...state, status: 'loading', error: null, unread: 0 }, action: 'reload' };
  }
}
```

```ts
import type { WebContentsView } from 'electron';
import { WHATSAPP_HOME_URL } from '../security/origins';
import { createAccountView, redactUrlsIn } from '../security/remoteContent';
import { initialRuntimeState, reduceRuntime, type RuntimeEvent, type RuntimeState } from './runtimeState';

export interface AccountRuntimeDeps {
  diag(line: string): void;
  /** Status or unread changed; the shell rebroadcasts state. */
  onChange(id: string): void;
  /** The page asked for focus (e.g. the user clicked one of its OS notifications): show this account. */
  onAttention(id: string): void;
}

/**
 * One account's WhatsApp view and its status (loading / ready / offline) and unread count, derived only
 * from webContents events and the page title. Never reads the DOM. Disposed runtimes ignore late events.
 */
export class AccountRuntime {
  readonly view: WebContentsView;
  private state: RuntimeState = initialRuntimeState();
  private disposed = false;
  /** Set while the shell itself focuses the view, so that focus event is not mistaken for a page request. */
  private ownFocus = false;

  constructor(
    readonly id: string,
    private readonly deps: AccountRuntimeDeps,
  ) {
    const tag = `[${id.slice(0, 8)}]`;
    this.view = createAccountView(id, {
      onPermission: (e) => deps.diag(`${tag} permission ${e.kind} ${e.permission} ${e.origin} -> ${e.allowed ? 'ALLOW' : 'DENY'} (${e.reason})`),
      onNavigation: (e) => deps.diag(`${tag} ${e.kind} ${e.url}`),
    });
    this.view.setBackgroundColor('#111b21');
    const wc = this.view.webContents;
    wc.on('did-start-loading', () => this.dispatch({ type: 'load-start' }));
    wc.on('did-finish-load', () => this.dispatch({ type: 'load-finish' }));
    wc.on('did-fail-load', (_e, code, description, _url, isMainFrame) => {
      if (isMainFrame) this.dispatch({ type: 'load-fail', code, description });
    });
    wc.on('render-process-gone', (_e, details) => {
      deps.diag(`${tag} render-process-gone ${details.reason}`);
      this.dispatch({ type: 'crash', reason: details.reason });
    });
    wc.on('page-title-updated', (_e, title) => this.dispatch({ type: 'title', title }));
    wc.on('did-navigate', () => void wc.session.cookies.flushStore());
    // WhatsApp's beforeunload handler would otherwise veto closing the window / quitting the app.
    wc.on('will-prevent-unload', (e) => e.preventDefault());
    wc.on('focus', () => {
      if (this.ownFocus) {
        this.ownFocus = false;
        return;
      }
      if (!this.disposed) deps.onAttention(id);
    });
  }

  snapshot(): Pick<RuntimeState, 'status' | 'error' | 'unread'> {
    const { status, error, unread } = this.state;
    return { status, error, unread };
  }

  load(): void {
    if (this.disposed) return;
    void this.view.webContents.loadURL(WHATSAPP_HOME_URL).catch((err: Error) => this.deps.diag(`[${this.id.slice(0, 8)}] load error ${redactUrlsIn(err.message)}`));
  }

  /** Reload button / menu: goes through the reducer so status and unread reset consistently. */
  reload(): void {
    this.dispatch({ type: 'reload' });
  }

  /** Shell-initiated focus (tab selected, window focused). The resulting focus event is swallowed. */
  focus(): void {
    if (this.disposed || this.view.webContents.isDestroyed()) return;
    this.ownFocus = true;
    this.view.webContents.focus();
    // If Chromium emits no focus event (hidden window), the flag must not swallow a later real one.
    setTimeout(() => (this.ownFocus = false), 500);
  }

  dispose(): void {
    if (this.disposed) return;
    this.disposed = true;
    this.view.webContents.removeAllListeners();
    if (!this.view.webContents.isDestroyed()) this.view.webContents.close();
  }

  private dispatch(event: RuntimeEvent): void {
    if (this.disposed) return;
    const { state, action } = reduceRuntime(this.state, event, Date.now());
    const changed = state.status !== this.state.status || state.error !== this.state.error || state.unread !== this.state.unread;
    this.state = state;
    if (action === 'reload') this.load();
    if (changed) this.deps.onChange(this.id);
  }
}
```

```ts
import { appendFileSync, mkdirSync, renameSync, statSync } from 'node:fs';
import { dirname } from 'node:path';

/**
 * Internal diagnostics (navigation blocks, permission decisions, downloads, status changes, crashes).
 * Goes to a bounded local file and, when enabled, to stdout. It never reaches any renderer.
 */
export interface DiagnosticsLog {
  (line: string): void;
  readonly file: string;
}

const MAX_BYTES = 5_000_000;

/** `MULTIWA_DIAG_CONSOLE=1` also prints diagnostics to stdout. */
export function diagConsoleEnabled(env: NodeJS.ProcessEnv = process.env): boolean {
  return env.MULTIWA_DIAG_CONSOLE === '1';
}

export function createDiagnosticsLog(file: string, opts: { console?: boolean } = {}): DiagnosticsLog {
  mkdirSync(dirname(file), { recursive: true });
  const toConsole = opts.console ?? diagConsoleEnabled();
  const log = (line: string) => {
    const entry = `${new Date().toISOString()} ${line}\n`;
    try {
      if ((statSync(file, { throwIfNoEntry: false })?.size ?? 0) > MAX_BYTES) renameSync(file, `${file}.1`);
      appendFileSync(file, entry);
    } catch {
      // Diagnostics must never break the app.
    }
    if (toConsole) process.stdout.write(`[diag] ${entry}`);
  };
  return Object.assign(log, { file });
}
```

```ts
import type { MessageBoxOptions } from 'electron';

/** The part of electron-updater's autoUpdater this module uses (injected so it can be tested). */
export interface UpdaterLike {
  autoDownload: boolean;
  autoInstallOnAppQuit: boolean;
  on(event: 'update-available', listener: (info: { version: string }) => void): unknown;
  on(event: 'update-not-available', listener: () => void): unknown;
  on(event: 'update-downloaded', listener: (info: { version: string }) => void): unknown;
  on(event: 'error', listener: (error: Error) => void): unknown;
  checkForUpdates(): Promise<unknown>;
  quitAndInstall(): void;
}

export interface UpdateServiceDeps {
  updater: UpdaterLike;
  /** Updates only apply to an installed (packaged) app; development runs never check. */
  enabled: boolean;
  currentVersion: string;
  showMessage: (options: MessageBoxOptions) => Promise<number>;
  log: (event: string, data?: Record<string, unknown>) => void;
}

const CHECK_EVERY_MS = 4 * 60 * 60 * 1000;

/**
 * Background auto-update: checks on launch and every few hours, downloads in the background and asks once per
 * version whether to restart now. A manual "Check for Updates…" also reports "up to date" and errors.
 */
export class UpdateService {
  private manual = false;
  private promptedVersion: string | null = null;
  private timer: NodeJS.Timeout | null = null;

  constructor(private readonly deps: UpdateServiceDeps) {
    const { updater } = deps;
    updater.autoDownload = true;
    updater.autoInstallOnAppQuit = true;
    updater.on('update-available', (info) => {
      deps.log('update.available', { version: info.version });
      if (this.manual) void this.deps.showMessage({ type: 'info', message: `Downloading version ${info.version}…`, detail: 'You will be asked to restart when it is ready.' });
      this.manual = false;
    });
    updater.on('update-not-available', () => {
      if (this.manual) void this.deps.showMessage({ type: 'info', message: 'MultiWA is up to date', detail: `Version ${deps.currentVersion}` });
      this.manual = false;
    });
    updater.on('update-downloaded', (info) => void this.promptRestart(info.version));
    updater.on('error', (error) => {
      deps.log('update.error', { message: error.message });
      if (this.manual) void this.deps.showMessage({ type: 'error', message: 'Could not check for updates', detail: error.message });
      this.manual = false;
    });
  }

  start(): void {
    if (!this.deps.enabled || this.timer) return;
    void this.check(false);
    this.timer = setInterval(() => void this.check(false), CHECK_EVERY_MS);
    this.timer.unref?.();
  }

  stop(): void {
    if (this.timer) clearInterval(this.timer);
    this.timer = null;
  }

  async check(manual = true): Promise<void> {
    if (!this.deps.enabled) {
      if (manual) await this.deps.showMessage({ type: 'info', message: 'Updates are only available in the installed app', detail: `Version ${this.deps.currentVersion} (development)` });
      return;
    }
    this.manual = manual;
    try {
      await this.deps.updater.checkForUpdates();
    } catch {
      // Reported through the 'error' event.
    }
  }

  private async promptRestart(version: string): Promise<void> {
    if (this.promptedVersion === version) return;
    this.promptedVersion = version;
    this.deps.log('update.downloaded', { version });
    const choice = await this.deps.showMessage({
      type: 'info',
      buttons: ['Restart Now', 'Later'],
      defaultId: 0,
      cancelId: 1,
      message: `Version ${version} is ready to install`,
      detail: 'Restart MultiWA to finish updating. If you choose Later, it is installed the next time you quit.',
    });
    if (choice === 0) this.deps.updater.quitAndInstall();
  }
}
```

```tsx
interface Props {

  activeId: string | null;
  onSelect(id: string): void;
  /** Called with the full new order after a drag-and-drop move. */
  onReorder(ids: string[]): void;
  /** Right-click: native per-account menu (main process). */
  onContextMenu(id: string): void;
  /** `+`: a new account tab opens WhatsApp Web right away. */

  onClose(id: string): void;

/** Pointer travel before a press becomes a drag (a shorter press is a click). */
const DRAG_THRESHOLD = 4;
const DROP_MS = 150;

interface Drag {
  id: string;
  from: number;
  startX: number;
  dx: number;
  /** Distance between two tab slots (tab width + gap), measured at drag start. */
  slot: number;
  active: boolean;
  dropping: boolean;
}

/** Index the dragged tab would land on for a horizontal offset. */
export function targetIndex(from: number, dx: number, slot: number, count: number): number {
  return Math.max(0, Math.min(count - 1, from + Math.round(dx / slot)));
}

/** Offset for a non-dragged tab at `index` while the dragged one moves from `from` to `to`. */
export function shiftFor(index: number, from: number, to: number, slot: number): number {
  if (from < to && index > from && index <= to) return -slot;
  if (from > to && index >= to && index < from) return slot;
  return 0;
}

function RenameInput({ initial, onCommit, onCancel }: { initial: string; onCommit(name: string): void; onCancel(): void }) {
  const [value, setValue] = useState(initial);
  const ref = useRef<HTMLInputElement>(null);
  useEffect(() => {
    ref.current?.focus();
    ref.current?.select();
  }, []);
  const commit = () => {
    const name = value.trim().replace(/\s+/g, ' ');
    if (name && name !== initial) onCommit(name);
    else onCancel();
  };
  return (
    <input
      ref={ref}
      className="tab-rename"
      value={value}
      maxLength={40}
      aria-label="Account name"
      onChange={(e) => setValue(e.target.value)}
      onBlur={commit}
      onKeyDown={(e) => {
        if (e.key === 'Enter') commit();
        else if (e.key === 'Escape') onCancel();
        e.stopPropagation();
      }}
      onPointerDown={(e) => e.stopPropagation()}
    />
  );
}

/**
 * Browser-style account tab strip (Sidekick's tab bar). Tabs are reordered by dragging: the other tabs slide
 * out of the way, the dragged tab settles on release. Double-click renames in place.
 */
export function TabBar({ accounts, activeId, onSelect, onReorder, onContextMenu, onNew, onClose, renamingId, onRenameStart, onRename, onRenameEnd }: Props) {
  const [drag, setDrag] = useState<Drag | null>(null);
  const dragRef = useRef<Drag | null>(null);
  const update = (d: Drag | null) => {
    dragRef.current = d;
    setDrag(d);
  };
  const to = drag ? targetIndex(drag.from, drag.dx, drag.slot, accounts.length) : -1;

  const onPointerDown = (e: React.PointerEvent<HTMLElement>, id: string, index: number) => {
    if (e.button !== 0 || dragRef.current || renamingId === id) return;
    const list = e.currentTarget.parentElement!;
    const items = list.querySelectorAll<HTMLElement>('.tab');
    const slot = items.length > 1 ? items[1]!.offsetLeft - items[0]!.offsetLeft : e.currentTarget.offsetWidth + 4;
    e.currentTarget.setPointerCapture(e.pointerId);
    update({ id, from: index, startX: e.clientX, dx: 0, slot, active: false, dropping: false });
  };

  const onPointerMove = (e: React.PointerEvent<HTMLElement>) => {
    const d = dragRef.current;
    if (!d || d.dropping) return;
    const dx = e.clientX - d.startX;
    if (!d.active && Math.abs(dx) < DRAG_THRESHOLD) return;
    update({ ...d, dx, active: true });
  };

  const onPointerUp = (e: React.PointerEvent<HTMLElement>, id: string) => {
    const d = dragRef.current;
    if (!d || d.dropping) return;
    if (e.currentTarget.hasPointerCapture(e.pointerId)) e.currentTarget.releasePointerCapture(e.pointerId);
    if (!d.active) {
      update(null);
      onSelect(id);
      return;
    }
    const dest = targetIndex(d.from, d.dx, d.slot, accounts.length);
    update({ ...d, dx: (dest - d.from) * d.slot, dropping: true });
    window.setTimeout(() => {
      if (dest !== d.from) {
        const ids = accounts.map((a) => a.id).filter((x) => x !== d.id);
        ids.splice(dest, 0, d.id);
        onReorder(ids);
      }
      update(null);
    }, DROP_MS);
  };

  const isMac = /Mac/i.test(navigator.platform);

  return (
    <header className="topbar">
      <nav className="tabs" aria-label="Accounts" role="tablist">
        <div className={`tab-list ${drag?.active ? 'reordering' : ''}`}>
          {accounts.map((a, index) => {
            const active = a.id === activeId;
            const isDragged = drag?.active && drag.id === a.id;
            let transform = '';
            if (drag?.active) transform = isDragged ? `translateX(${drag.dx}px) scale(${drag.dropping ? 1 : 1.03})` : `translateX(${shiftFor(index, drag.from, to, drag.slot)}px)`;
            const statusTitle = a.status === 'offline' ? ` — offline${a.error ? `: ${a.error}` : ''}` : a.status === 'loading' ? ' — loading' : '';
            return (
              <div
                key={a.id}
                role="tab"
                tabIndex={0}
                className={`tab ${active ? 'active' : ''} ${a.status} ${isDragged ? 'dragging' : ''} ${isDragged && drag.dropping ? 'dropping' : ''}`}
                style={{ transform: transform || undefined }}
                title={`${a.name}${statusTitle}`}
                aria-selected={active}
                onPointerDown={(e) => onPointerDown(e, a.id, index)}
                onPointerMove={onPointerMove}
                onPointerUp={(e) => onPointerUp(e, a.id)}
                onPointerCancel={() => update(null)}
                onDoubleClick={() => onRenameStart(a.id)}
                onContextMenu={(e) => {
                  e.preventDefault();
                  if (!dragRef.current?.active) onContextMenu(a.id);
                }}
                onKeyDown={(e) => {
                  if (e.target === e.currentTarget && (e.key === 'Enter' || e.key === ' ')) onSelect(a.id);
                }}
              >
                <span className="tab-dot" style={{ background: a.color }} />
                {renamingId === a.id ? (

                  <span className="tab-name">{a.name}</span>
                )}
                {a.status === 'loading' && <span className="tab-badge loading" aria-hidden="true" />}
                {a.status === 'offline' && <span className="tab-badge offline" aria-label="Offline" />}
                {a.unread > 0 && a.status !== 'offline' && <span className="tab-unread" aria-label={`${a.unread} unread`}>{a.unread > 99 ? '99+' : a.unread}</span>}

          </button>
        </div>
      </nav>
    </header>
  );
}
```

```ts
/**
 * Product shell: account tab strip, one WhatsApp WebContentsView per account, optional right pane, several
 * windows. Wires the tested modules (store, layout, runtimes, downloads) to Electron.

export async function startShell(): Promise<{ focusMainWindow: () => void }> {
  const userData = app.getPath('userData');
  const diag = createDiagnosticsLog(join(userData, 'logs', 'events.log'));
  const store = new AppStateStore(join(userData, 'app-state.json'), 150, diag);
  const runtimes = new Map<string, AccountRuntime>();
  const windows = new Map<string, ShellWindow>(); // by WindowRecord id
  const windowOf = new Map<string, ShellWindow>(); // accountId -> window
  let quitting = false;

  // ---------- Shell page / renderer ----------

  const shellPageUrl = process.env.ELECTRON_RENDERER_URL ? `${process.env.ELECTRON_RENDERER_URL}/shell/index.html` : pathToFileURL(join(__dirname, '../renderer/shell/index.html')).href;

  const loadShellRenderer = async (sw: ShellWindow) => {
    if (process.env.ELECTRON_RENDERER_URL) await sw.win.loadURL(shellPageUrl);
    else await sw.win.loadFile(join(__dirname, '../renderer/shell/index.html'));
  };

  const mainWindow = (): ShellWindow => windows.get(MAIN_WINDOW_ID)!;
  const focusedWindow = (): ShellWindow => {
    const f = BrowserWindow.getFocusedWindow();
    for (const sw of windows.values()) if (f && sw.win === f) return sw;
    return mainWindow();
  };
  const tabsIn = (sw: ShellWindow) => store.accounts().filter((a) => windowOf.get(a.id) === sw).map((a) => a.id);
  const sendCommand = (sw: ShellWindow, c: ShellCommand) => {
    if (!sw.win.isDestroyed()) sw.win.webContents.send(SHELL_CHANNELS.command, c);
  };

  // ---------- Windows ----------

  function persistWindow(sw: ShellWindow): void {
    if (sw.win.isDestroyed()) return;
    const b = sw.win.getNormalBounds();
    store.upsertWindow({
      id: sw.id,
      isMain: sw.id === MAIN_WINDOW_ID,
      bounds: { x: b.x, y: b.y, width: b.width, height: b.height },
      activeAccountId: sw.layout.activeId,
      splitRatio: sw.layout.ratio,
      rightPaneAccountId: sw.layout.rightId,
    });
  }

  function createShellWindow(record: WindowRecord): ShellWindow {
    const bounds: Partial<Rectangle> = record.bounds ?? {};
    const win = new BrowserWindow({
      width: 1400,
      height: 900,
      ...bounds,
      minWidth: 900,
      minHeight: 560,
      title: APP_TITLE,
      // The tab strip doubles as the title bar: traffic lights sit inside it and its empty space drags the window.
      ...(isWindows
        ? { titleBarStyle: 'hidden' as const, titleBarOverlay: { color: '#e8e8ea', symbolColor: '#1f1f1f', height: TOPBAR_HEIGHT - 1 }, autoHideMenuBar: true }
        : { titleBarStyle: 'hiddenInset' as const, trafficLightPosition: { x: 16, y: 15 } }),
      backgroundColor: '#111b21',
      show: false,
      webPreferences: { preload: join(__dirname, '../preload/shell.js'), contextIsolation: true, sandbox: true, nodeIntegration: false, webSecurity: true, spellcheck: false },
    });
    win.once('ready-to-show', () => win.show());
    // The shell renderer never navigates or opens windows itself.
    win.webContents.on('will-navigate', (e) => e.preventDefault());
    win.webContents.setWindowOpenHandler(() => ({ action: 'deny' }));

    const layout = new PaneLayoutController(
      () => {
        const [w, h] = win.getContentSize();
        return workAreaFor(w!, h!);
      },
      record.splitRatio,
      () => persistWindow(sw),
    );
    const sw: ShellWindow = { id: record.id, win, layout };
    windows.set(record.id, sw);

    win.on('enter-full-screen', () => sendCommand(sw, 'fullscreen-enter'));
    win.on('leave-full-screen', () => sendCommand(sw, 'fullscreen-leave'));
    win.on('resize', () => {
      layout.relayout();
      persistWindow(sw);
    });
    win.on('move', () => persistWindow(sw));
    win.on('focus', () => {
      if (isWindows) win.flashFrame(false);
      const id = layout.activeId;
      if (id) runtimes.get(id)?.focus();
    });
    win.on('close', (e) => {
      if (quitting) return;
      if (sw.id === MAIN_WINDOW_ID) {
        // macOS: the main window hides (Dock keeps the app alive); elsewhere closing it quits.
        if (isMac) {
          e.preventDefault();
          win.hide();
          return;
        }
        quitting = true;
        app.quit();
        return;
      }
      // A secondary window hands its tabs back to the main window; runtimes keep running.
      const main = mainWindow();
      for (const id of tabsIn(sw)) attachTab(id, main);
      store.removeWindow(sw.id);
      afterTabsChanged(main);
      if (!main.win.isVisible()) main.win.show();
    });
    win.on('closed', () => {
      if (sw.id !== MAIN_WINDOW_ID) windows.delete(sw.id);
      for (const [id, owner] of windowOf) if (owner === sw) windowOf.delete(id);
      broadcast();
    });
    return sw;
  }

  /** Puts a tab's view into `sw` (taking it out of its current window) without selecting it. */
  function attachTab(id: string, sw: ShellWindow): void {
    const rt = runtimes.get(id);
    if (!rt) return;
    const from = windowOf.get(id);
    if (from === sw) return;
    if (from) {
      from.layout.unregister(id);
      if (!from.win.isDestroyed()) from.win.contentView.removeChildView(rt.view);
    }
    sw.win.contentView.addChildView(rt.view);
    sw.layout.register(id, rt.view);
    sw.layout.setHidden(id, rt.snapshot().status === 'offline');
    windowOf.set(id, sw);
    if (store.account(id)?.windowId !== sw.id) store.updateAccount(id, { windowId: sw.id });
  }

  // ---------- State to renderers ----------

  function accountViews(): AccountView[] {
    return store
      .accounts()
      .filter((a) => runtimes.has(a.id))
      .map((a) => ({ id: a.id, name: a.name, color: a.color, ...runtimes.get(a.id)!.snapshot() }));
  }
  const windowState = (sw: ShellWindow, all = accountViews()): ShellState => stateForWindow(all, (id) => windowOf.get(id) === sw, sw.layout.activeId, sw.layout.rightId, sw.layout.ratio);

  let broadcastQueued = false;
  function broadcast(): void {
    if (broadcastQueued) return;
    broadcastQueued = true;
    setTimeout(() => {
      broadcastQueued = false;
      const all = accountViews();
      for (const sw of windows.values()) if (!sw.win.isDestroyed()) sw.win.webContents.send(SHELL_CHANNELS.state, windowState(sw, all));
      app.setBadgeCount(all.reduce((n, a) => n + a.unread, 0));
    }, 16);
  }

  const sendToast = (t: Omit<ToastMessage, 'id'>) => {
    const sw = (t.accountId && windowOf.get(t.accountId)) || focusedWindow();
    if (!sw.win.isDestroyed()) sw.win.webContents.send(SHELL_CHANNELS.toast, { ...t, id: randomUUID() });
  };

  /** Brings a window and an account tab to the front (notification click, page focus request). */
  function bringToFront(id: string): void {
    const sw = windowOf.get(id);
    if (!sw || sw.win.isDestroyed()) return;
    if (sw.layout.activeId !== id && sw.layout.rightId !== id) selectAccount(id);
    if (sw.win.isMinimized()) sw.win.restore();
    if (!sw.win.isVisible()) sw.win.show();
    if (!sw.win.isFocused()) sw.win.focus();
  }

  // ---------- Downloads ----------

  const downloads = new DownloadManager({
    downloadsDir: () => app.getPath('downloads'),
    onEvent: (e) => {
      diag(`[${e.accountId.slice(0, 8)}] download ${e.kind} ${e.filename}`);
      if (e.kind === 'done') {
        sendToast({ accountId: e.accountId, kind: 'success', title: `Saved ${e.filename}`, body: 'Click to show in folder', downloadId: e.id });
        const owner = windowOf.get(e.accountId);
        if (Notification.isSupported() && (!owner || !owner.win.isFocused())) {
          const note = new Notification({ title: 'Download finished', body: e.filename, silent: true });
          note.on('click', () => downloads.reveal(e.id));
          note.show();
        }
      } else sendToast({ accountId: e.accountId, kind: 'error', title: `Download ${e.state}`, body: e.filename });
    },
  });

  // ---------- Account runtimes ----------

  const lastStatus = new Map<string, AccountView['status']>();
  function createRuntime(a: AccountRecord, sw: ShellWindow): AccountRuntime {
    const rt = new AccountRuntime(a.id, {
      diag,
      onChange: (id) => {
        const owner = windowOf.get(id);
        const r = runtimes.get(id);
        if (!r) return;
        const { status, error } = r.snapshot();
        owner?.layout.setHidden(id, status === 'offline');
        const wentOffline = status === 'offline' && lastStatus.get(id) !== 'offline';
        lastStatus.set(id, status);
        if (wentOffline) diag(`[${id.slice(0, 8)}] offline ${error ?? ''}`);
        if (wentOffline && owner && !owner.win.isFocused() && Notification.isSupported()) {
          const name = store.account(id)?.name ?? 'Account';
          new Notification({ title: `${name} is offline`, body: error ?? '', silent: true }).show();
        }
        broadcast();
      },
      onAttention: (id) => bringToFront(id),
    });
    runtimes.set(a.id, rt);
    downloads.attach(rt.view.webContents.session, a.id);
    attachTab(a.id, sw);
    rt.load();
    return rt;
  }

  function destroyRuntime(id: string): void {
    const rt = runtimes.get(id);
    const sw = windowOf.get(id);
    runtimes.delete(id);
    windowOf.delete(id);
    lastStatus.delete(id);
    sw?.layout.unregister(id);
    if (rt) {
      if (sw && !sw.win.isDestroyed()) sw.win.contentView.removeChildView(rt.view);
      rt.dispose();
    }
  }

  function selectAccount(id: string): void {
    const a = store.account(id);
    const sw = windowOf.get(id);
    if (!a || !runtimes.has(id) || !sw) return;
    sw.layout.activate(id);
    runtimes.get(id)?.focus();
    sw.win.setTitle(a.name);
    persistWindow(sw);
    broadcast();
  }

  function addAccount(sw: ShellWindow): string {
    const all = store.accounts();
    const record: AccountRecord = {
      id: randomUUID(),
      name: nextAccountName(all.map((a) => a.name)),
      color: colorForNew(all.map((a) => a.color)),
      order: all.reduce((m, a) => Math.max(m, a.order), -1) + 1,
      windowId: sw.id,
      createdAt: new Date().toISOString(),
    };
    store.addAccount(record);
    createRuntime(record, sw);
    selectAccount(record.id);
    diag(`[${record.id.slice(0, 8)}] account added`);
    return record.id;
  }

  /** Removes the account, its view and its whole session partition. */
  async function removeAccount(id: string): Promise<void> {
    const sw = windowOf.get(id);
    const ses = runtimes.get(id)?.view.webContents.session ?? session.fromPartition(partitionFor(id));
    destroyRuntime(id);
    store.removeAccount(id);
    afterTabsChanged(sw ?? mainWindow());
    try {
      await ses.clearStorageData();
      await ses.clearCache();
    } catch (err) {
      diag(`[${id.slice(0, 8)}] clearStorageData failed: ${err instanceof Error ? err.message : String(err)}`);
    }
    // Electron keeps a `persist:` partition under <userData>/Partitions/<name>; remove what clearStorageData left.
    rmSync(join(userData, 'Partitions', `wa-${id}`), { recursive: true, force: true });
    diag(`[${id.slice(0, 8)}] account removed`);
  }

  function confirmRemove(sw: ShellWindow, id: string): boolean {
    const a = store.account(id);
    if (!a) return false;
    const choice = dialog.showMessageBoxSync(sw.win, {
      type: 'warning',
      buttons: ['Cancel', 'Remove'],
      defaultId: 0,
      cancelId: 0,
      message: `Remove “${a.name}”?`,
      detail: "This account's WhatsApp session is removed from this computer. You will need to scan the QR code again to add it back. Nothing on your phone is changed.",
    });
    return choice === 1;
  }

  /** A window whose tabs changed shows its current or first remaining tab; an emptied secondary window closes. */
  function afterTabsChanged(sw: ShellWindow | undefined): void {
    if (!sw || sw.win.isDestroyed()) return broadcast();
    const ordered = store.accounts().map((a) => a.id);
    const next = nextActiveTab(ordered, (id) => windowOf.get(id) === sw, sw.layout.activeId);
    if (sw.layout.rightId && !windowOf.has(sw.layout.rightId)) sw.layout.setRight(null);
    if (next) selectAccount(next);
    else if (sw.id !== MAIN_WINDOW_ID) sw.win.close();
    else {
      sw.win.setTitle(APP_TITLE);
      persistWindow(sw);
    }
    broadcast();
  }

  function moveTab(id: string, to: ShellWindow): void {
    const from = windowOf.get(id);
    if (!from || from === to) return;
    if (from.layout.rightId === id) from.layout.setRight(null);
    attachTab(id, to);
    selectAccount(id);
    if (to.win.isVisible()) to.win.focus();
    afterTabsChanged(from);
  }

  function moveTabToNewWindow(id: string): void {
    const from = windowOf.get(id);
    if (!from) return;
    const b = from.win.getBounds();
    const record: WindowRecord = { id: randomUUID(), isMain: false, bounds: { x: b.x + 30, y: b.y + 30, width: b.width, height: b.height }, activeAccountId: id, splitRatio: 0.5, rightPaneAccountId: null };
    store.upsertWindow(record);
    const sw = createShellWindow(record);
    void loadShellRenderer(sw);
    moveTab(id, sw);
  }

  function showInRightPane(sw: ShellWindow, id: string): void {
    if (windowOf.get(id) !== sw) moveTab(id, sw);
    if (sw.layout.activeId === id) {
      // Asked to show the active account on the right: put the previous right account (or the next tab) on the left.
      const other = sw.layout.rightId ?? tabsIn(sw).find((x) => x !== id);
      if (!other) return;
      sw.layout.activate(other);
    }
    sw.layout.setRight(id);
    persistWindow(sw);
    broadcast();
  }

  function hideRightPane(sw: ShellWindow): void {
    sw.layout.setRight(null);
    persistWindow(sw);
    broadcast();
  }

  // ---------- IPC (trusted shell renderer only) ----------

  const fromShell = (e: IpcMainInvokeEvent | IpcMainEvent): ShellWindow | undefined => {
    const frame = e.senderFrame;
    if (!frame || !isShellPage(frame.url)) return undefined;
    for (const sw of windows.values()) if (!sw.win.isDestroyed() && e.sender === sw.win.webContents && frame === sw.win.webContents.mainFrame) return sw;
    return undefined;
  };
  const handleIn = (channel: string, fn: (sw: ShellWindow, ...args: unknown[]) => unknown) =>
    ipcMain.handle(channel, async (e, ...args) => {
      const sw = fromShell(e);
      if (!sw) throw new Error('unauthorized sender');
      return fn(sw, ...args);
    });
  const onIn = (channel: string, fn: (sw: ShellWindow, arg: unknown) => void) =>
    ipcMain.on(channel, (e, arg) => {
      const sw = fromShell(e);
      if (sw) fn(sw, arg);
    });
  const known = (id: unknown): id is string => isId(id) && runtimes.has(id);

  handleIn('shell:get-state', (sw) => windowState(sw));
  handleIn('account:add', (sw) => ({ ok: true, id: addAccount(sw) }));
  handleIn('account:select', (_sw, id) => {
    if (known(id)) selectAccount(id);
  });
  handleIn('account:rename', (sw, id, name) => {
    if (!known(id)) return { ok: false, detail: 'Account not found.' };
    const n = validateAccountName(name);
    if (!n) return { ok: false, detail: 'Enter a name (1–40 characters).' };
    store.updateAccount(id, { name: n });
    if (sw.layout.activeId === id) sw.win.setTitle(n);
    broadcast();
    return { ok: true };
  });
  handleIn('account:remove', async (sw, id) => {
    if (!known(id)) return { ok: false, detail: 'Account not found.' };
    if (!confirmRemove(sw, id)) return { ok: false, code: 'cancelled' };
    if (!known(id)) return { ok: false, detail: 'Account not found.' };
    await removeAccount(id);
    return { ok: true };
  });
  // A window reorders only its own tabs; tabs of other windows keep their slots in the global order.
  handleIn('account:reorder', (sw, ids) => {
    if (!Array.isArray(ids) || !ids.every(isId)) return { ok: false };
    const merged = mergeWindowOrder(store.accounts().map((a) => a.id), (id) => windowOf.get(id) === sw, ids);
    if (!merged || !store.reorderAccounts(merged)) return { ok: false };
    broadcast();
    return { ok: true };
  });
  handleIn('account:context-menu', (sw, id) => {
    if (!known(id)) return;
    const owner = windowOf.get(id);
    const inRight = owner?.layout.rightId === id;
    const moves: MenuItemConstructorOptions[] = [
      ...(owner && tabsIn(owner).length > 1 ? [{ label: 'Move to New Window', click: () => moveTabToNewWindow(id) }] : []),
      ...(owner && owner.id !== MAIN_WINDOW_ID ? [{ label: 'Move to Main Window', click: () => moveTab(id, mainWindow()) }] : []),
    ];
    Menu.buildFromTemplate([
      { label: 'Rename…', click: () => selectAndRename(sw, id) },
      inRight ? { label: 'Hide Right Pane', click: () => hideRightPane(sw) } : { label: 'Show in Right Pane', enabled: tabsIn(sw).length > 1 || windowOf.get(id) !== sw, click: () => showInRightPane(sw, id) },
      { type: 'separator' },
      ...(moves.length ? [...moves, { type: 'separator' } as const] : []),
      { label: 'Reload', click: () => runtimes.get(id)?.reload() },
      { type: 'separator' },
      {
        label: 'Remove Account…',
        click: () => {
          if (confirmRemove(sw, id) && known(id)) void removeAccount(id);
        },
      },
    ]).popup({ window: sw.win });
  });
  handleIn('account:reload', (_sw, id) => {
    if (known(id)) runtimes.get(id)!.reload();
  });
  handleIn('split:show', (sw, id) => {
    if (known(id)) showInRightPane(sw, id);
  });
  handleIn('split:hide', (sw) => hideRightPane(sw));
  handleIn('download:reveal', (_sw, id) => {
    if (isId(id)) downloads.reveal(id);
  });
  // Fire-and-forget so dragging stays smooth: only setBounds on existing views.
  onIn('layout:set-split', (sw, arg) => {
    const { ratio, commit } = (arg ?? {}) as { ratio?: unknown; commit?: unknown };
    if (!isValidSplitRatio(ratio) || sw.layout.rightId === null) return;
    if (commit === true) {
      sw.layout.commit(ratio);
      broadcast();
    } else sw.layout.preview(ratio);
  });

  const selectAndRename = (sw: ShellWindow, id: string) => {
    selectAccount(id);
    sendCommand(windowOf.get(id) ?? sw, 'rename-active');
  };

  // ---------- Menu ----------

  const activeRuntime = () => {
    const id = focusedWindow().layout.activeId;
    return id ? runtimes.get(id) : undefined;
  };
  const zoom = (delta: number | null) => {
    const wc = activeRuntime()?.view.webContents;
    if (!wc) return;
    wc.setZoomLevel(delta === null ? 0 : Math.max(-3, Math.min(3, wc.getZoomLevel() + delta)));
  };
  const cycleTab = (dir: 1 | -1) => {
    const sw = focusedWindow();
    const ids = tabsIn(sw);
    if (ids.length < 2) return;
    const i = Math.max(0, ids.indexOf(sw.layout.activeId ?? ''));

  // ---------- Lifecycle ----------

  app.on('before-quit', () => {

  // ---------- Startup ----------

  const first = createShellWindow(store.mainWindowRecord());
  await loadShellRenderer(first);

  const accounts = store.accounts();
  // Secondary windows are restored only when at least one account still lives in them.
  for (const rec of store.windows()) {

    void loadShellRenderer(sw);

    if (rec.rightPaneAccountId && ids.includes(rec.rightPaneAccountId) && rec.rightPaneAccountId !== active) sw.layout.setRight(rec.rightPaneAccountId);
  }
  broadcast();
  updates.start();
  diag(`lifecycle started v${app.getVersion()} accounts=${accounts.length}`);

  return {
    focusMainWindow: () => {
      const { win } = first;
      if (win.isDestroyed()) return;
      if (win.isMinimized()) win.restore();
      win.show();
      win.focus();
    },
  };
}
```

```ts
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';
import { describe, expect, it } from 'vitest';

/**
 * Architectural boundaries (spec §5):
 * - domain code is Electron-free and imports nothing from main/renderer;
 * - remote-content-side modules (security, accounts, downloads) never import renderer code and never push to a renderer;
 * - the renderer never imports main-process code;
 * - the preload exposes no generic IPC channel access.
 */
const SRC = join(__dirname, '..');

function files(dir: string): string[] {
  return readdirSync(dir).flatMap((name) => {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) return name === '__tests__' ? [] : files(p);
    return /\.(ts|tsx)$/.test(name) ? [p] : [];
  });
}
const offenders = (list: string[], patterns: RegExp[]) =>
  list.flatMap((f) => {
    const text = readFileSync(f, 'utf8');
    return patterns.filter((re) => re.test(text)).map((re) => `${relative(SRC, f)} ~ ${re}`);
  });

describe('isolation boundaries', () => {
  it('domain modules import neither electron nor main/renderer code', () => {
    const domain = files(join(SRC, 'domain'));
    expect(domain.length).toBeGreaterThan(3);
    expect(offenders(domain, [/from ['"]electron['"]/, /from ['"][^'"]*\/main\//, /from ['"][^'"]*\/renderer\//])).toEqual([]);
  });
  it('remote-content-side modules never import renderer code or push to a renderer', () => {
    const remoteSide = ['main/security', 'main/accounts', 'main/downloads', 'main/diagnostics'].flatMap((d) => files(join(SRC, d)));
    expect(remoteSide.length).toBeGreaterThan(5);
    expect(offenders(remoteSide, [/from ['"][^'"]*\/renderer\//, /webContents\.send\(/, /ipcMain/])).toEqual([]);
  });
  it('the renderer never imports main-process code or electron', () => {
    const renderer = files(join(SRC, 'renderer'));
    expect(offenders(renderer, [/from ['"][^'"]*\/main\//, /from ['"]electron['"]/])).toEqual([]);
  });
  it('the preload exposes fixed channels only', () => {
    const preload = readFileSync(join(SRC, 'preload/shell.ts'), 'utf8');
    expect(preload).not.toMatch(/exposeInMainWorld\([^)]*ipcRenderer\b/);
    expect(preload).not.toMatch(/invoke\(\s*[a-z]\w*\s*[,)]/i); // every invoke names a literal channel
```

```markdown
# MultiWA Security

MultiWA embeds remote web content (WhatsApp Web) for several accounts at once. These rules are architectural requirements.

## Trust model
Trusted: packaged MultiWA code, validated local user actions. Untrusted: everything from `web.whatsapp.com` (DOM, titles, notification bodies, download names, URLs).

## Remote content (account views)
- `nodeIntegration:false`, `contextIsolation:true`, `sandbox:true`, `webSecurity:true`, `allowRunningInsecureContent:false`, no experimental features, `webviewTag:false`.
- **No preload, no bridge, no `executeJavaScript`.** The only page signals read are the title, load/crash events and `will-download`.
- Top-level navigation only to `https://*.whatsapp.com` / `https://*.whatsapp.net`; everything else is blocked and, if `http(s)`, opened in the OS browser (rate-limited). `window.open` is always denied in-app.
- Permissions granted to the WhatsApp main frame only: `media` (audio/video), `notifications`, `clipboard-read`, `clipboard-sanitized-write`, `fullscreen`. All others and all other origins denied. Device (USB/HID/serial/Bluetooth) and display-capture requests denied.
- One session partition per account; partitions never share cookies or storage.

## Shell renderer
Packaged code, sandboxed, typed `contextBridge` with fixed channels. No `ipcRenderer`, `fs`, `child_process`, session objects or arbitrary channels exposed.

## IPC
Every handler verifies the sender frame is the bundled shell page in a known shell window and validates input shapes. Downloads are revealed by id; the renderer never names a path.

## Downloads
Saved only under `app.getPath('downloads')` with a sanitized, unique basename (`downloadTarget.ts`). No dialog, no execution.

## Logging
`<userData>/logs/events.log`: navigation decisions (origin + path only), permission decisions, download outcomes, status changes. Never titles, notification bodies or query strings.

## Packaging
Hardened runtime, notarized macOS builds, Electron fuses (`runAsNode` off, asar integrity on, only-load-from-asar on). Windows builds are unsigned for now.

## Reporting
Open a private security advisory on the GitHub repository.
```
